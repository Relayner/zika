# 字卡 (zika) — PWA карточек китайского

**Это отдельный, самостоятельный проект. Он не связан ни с одним другим проектом на этой машине.**

## Границы работы — строго

- Работать **только внутри `~/projects/VicChin`**. Это отдельный git-репозиторий (`Relayner/zika`).
- **Не читать, не изменять и не коммитить** ничего в соседних папках: `~/projects/CRM` (CRM INOPRO), `~/projects/The Game`, `~/projects/TT-Retail`, `~/projects/Pitch` и прочих. Они к этому проекту не относятся.
- Единственное разрешённое исключение: файл ключей `~/projects/the-game-godot/.env` — **только чтение** ключа Recraft для генерации картинок.
- Ничего не удалять за пределами `tools/gen/raw/` (пересоздаваемые исходники картинок). Файлы пользователя не трогать никогда.

## Что это

PWA (устанавливается на домашний экран iPhone), задеплоена на GitHub Pages: https://relayner.github.io/zika/

- Карточки китайского: иероглиф · пиньинь · русский перевод; свои колоды; HSK 1–3 встроены.
- Пять режимов тренировки: выбор, письмо 写, аудирование 听, предложения 句, перелистывание.
- **Настоящие экзамены HSK 1–3** в реальном формате (听力 / 阅读 / 书写), со случайными вариантами. HSKK (говорение) — в разработке.
- Геймификация: кот-воин эпохи Трёх Царств, 10 рангов, поход на 30 дней, сундуки с сокровищами.
- Пуши от дракона-наставника Луна (Cloudflare Worker `zika-push`).

## Устройство

- Исходники — в `src/` (`src/js/*.js`, `src/css/style.css`, `src/img/*.webp`).
- `node build.mjs` собирает всё в **один файл** `docs/index.html` (+ `docs/artifact.html`). Порядок скриптов — в `JS_ORDER` внутри `build.mjs`.
- **Никогда не редактировать `docs/index.html` руками** — он перезаписывается сборкой.
- Тесты: `node test/core.test.mjs` (должно быть 0 строк `FAIL`).
- Деплой: собрать → закоммитить → `git push origin main`, GitHub Pages подхватывает `docs/` примерно за 25 секунд.
- Картинки генерируются через Recraft: `python3 tools/make_art.py --only pic-p28`. Каждую новую картинку **обязательно смотреть глазами** (инструментом Read) — генератор регулярно ошибается и иногда впечатывает английский текст.

## Железные правила

1. **Прогресс пользователя неприкосновенен.** Данные лежат в IndexedDB (`kv` + `attempts`), схема версионируется в `src/js/vault.js`. Миграции — только дополняющие, с бэкапом перед изменением. Ничего, что может стереть попытки, очки, ранги или сокровища.
2. Изменения проверять в браузере (preview-инструменты), а не «на глаз по коду».
3. Экзамены HSK не настраиваются пользователем — формат фиксированный, как на реальном экзамене.
4. Интерфейс — на русском, тексты заданий — на китайском. Длинные тексты не должны переноситься криво: лучше кнопка «i» с пояснением.
