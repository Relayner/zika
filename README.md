# 字卡 — карточки китайского (PWA для iPhone)

Флэш-карточки: иероглиф · пиньинь · русский перевод. Встроенные словари HSK 1–3 (стандарт HSK 2.0: 150 / 150 / 300 слов),
билдер своих колод, тесты трёх уровней сложности, режим переворота, HSK-тесты с порогом 60 %, подробная статистика.
Всё хранится только на телефоне (IndexedDB), работает офлайн, сети не требует.

## Поделиться с другим человеком
Хостинг делает это автоматически: человек открывает ту же ссылку в Safari и добавляет на экран «Домой» — без каких-либо аккаунтов.
Данные (колоды, статистика) у каждого свои, на его телефоне. Обменяться колодой — «Экспорт» → переслать текст → «Импорт текстом».
Готовый архив для загрузки на хостинг (Netlify Drop, GitHub Pages, Cloudflare Pages): `zika-dist.zip`.

## Адрес
Сайт: **https://relayner.github.io/zika/** (GitHub Pages из папки `docs/` ветки `main`, репозиторий https://github.com/Relayner/zika).
Обновить: `node build.mjs` → `git add -A && git commit` → `git push` — через минуту новая версия на сайте; установленное

## Установка на iPhone
1. Открыть https://relayner.github.io/zika/ в Safari → **Поделиться** → **На экран «Домой»**.
3. Запускать с иконки: полный экран, офлайн, данные сохраняются между запусками.

Резервная копия (колоды + вся статистика) — «Настройки → Экспорт» → сохранить в «Файлы»/iCloud; восстановить — «Импорт».

## Структура
- `src/js/hsk.js` — словари HSK 1–3 `[иероглиф, пиньинь, перевод]`
- `src/js/pinyin.js` — `ni3 hao3 → nǐ hǎo`, сравнение с тонами и без
- `src/js/quiz.js` — отбор карточек, варианты (похожие на среднем уровне), проверка ввода, баллы
- `src/js/stats.js` — агрегаты по попыткам, серии дней, по-дневные графики
- `src/js/store.js` — IndexedDB → localStorage → память
- `src/js/audio.js` — синтез звуков (клик, переворот, удача, неудача, финал)
- `src/js/app.js`, `views-*.js` — интерфейс; `src/css/style.css` — стиль (бумага, тушь, киноварь, бордо, золото)

## Как считается
- Результат (%) = средняя доля верных частей по вопросам; пиньинь без тонов = 0,5.
- Балл = % × множитель сложности (лёгкий ×1, средний ×1,5, сложный ×2).
- «Освоено» — карточка отвечена верно 3 раза подряд; «проблемная» — точность < 60 % при ≥ 2 вопросах.
- HSK-экзамен — формат фиксированный (сложность не выбирается), по духу HSK 2.0:
  - HSK 1 — 20 вопросов, выбор из 4, пиньинь подписан, 20 с на вопрос, балл из 200, порог 120;
  - HSK 2 — 30 вопросов, выбор из 4 похожих, пиньинь подписан, 20 с, балл из 200, порог 120;
  - HSK 3 — 30 вопросов без пиньиня + 10 на написание иероглифов с клавиатуры, 25 с, балл из 300, порог 180.
  Вопросы чередуют «иероглиф → перевод» и «перевод → иероглиф». Свободная тренировка по словарю HSK — кнопка «Учить».
- Режим «Письмо 写» — набор иероглифов с китайской клавиатуры iOS (лёгкий: перевод + пиньинь, средний: только пиньинь, сложный: только перевод).
- Режим «Аудио 听» — слово озвучивается китайским голосом iOS (speechSynthesis, офлайн); лёгкий — 4 варианта с пиньинем и переводом, средний — 8 похожих по звучанию иероглифов, сложный — ввод (иероглифы или пиньинь с тонами). Банк: HSK 1–3 + колода «Частотные слова» (`src/js/freq.js`) ≈ 1180 слов.
- Режим «Фразы 句» — вопрос по-китайски с однозначным ответом (`src/js/sentences.js`, 104 фразы); лёгкий — выбор из 4 с пиньинем/переводом, средний — 8 похожих, сложный — ответ иероглифами.
- Настройки тренировок раздельные по режимам (`settings.lastSetup.byMode`); экзамены HSK настроек не читают.
- Надёжность статистики: попытки пишутся сразу с повтором и резервной очередью в localStorage; `persistNow()` на сворачивание; ежедневный бэкап включает попытки. Интернет для сохранения не нужен.
- Наставник Лун (`src/js/dragon.js`, `dragon-1..4.webp`): с полудня напоминает на главной, настроение = время × недобранные очки; полноэкранное появление раз в день при высокой злобе; бейдж на иконке после полудня, пока переход не набран. Настоящие пуши требуют сервера — не реализованы.

## Настоящий экзамен HSK (формат реального экзамена)
`src/js/hsk1exam.js` (банки заданий), `src/js/hskreal.js` (сборка варианта), `src/js/views-hskexam.js` (плеер).
HSK 1: 听力 20 вопросов (4 части: слово+картинка 对/错, предложение→картинка, диалог→картинка, вопрос→ответ; каждое аудио
дважды через TTS, на ответ 12 с) + 阅读 20 вопросов (4 части: слово+картинка, предложение→картинка, подбор ответов из пула,
слово в пропуск; секция 17 минут). Проверка только в конце; секции по 100 баллов, сдано от 120/200. Вариант собирается
случайно из банков. Картинки `pic-p01…p40` (Recraft; p30–p40 ещё не сгенерированы — кончились кредиты, движок фильтрует по
`PICS_AVAILABLE` из сборки). Словарные тесты HSK остались как «Словарный тест»; HSK 2–3 настоящий формат — следующие части;
говорение — отдельный экзамен HSKK (будет через распознавание речи).

## Пуши (сервер)
`push-server/`: Cloudflare Worker — подписки и отчёты в KV, крон каждые 30 мин шлёт Web Push (чистый WebCrypto,
RFC 8291/8292, тесты в `test/push.test.mjs`). VAPID-ключи: публичный в `src/pushconf.json`, приватный в `push-server/.dev.vars`
(в git не попадает). Деплой: `npx wrangler login` (владелец) → `push-server/deploy.sh` → вписать URL воркера в
`src/pushconf.json` → пересобрать и запушить сайт. Клиент: `src/js/push.js`, приём — в `sw.js`, тумблер в настройках.

## Поход (геймификация)
Персонаж — кот-воин эпохи Троецарствия, 10 рангов от кашевара до бога войны (`src/js/cats.js`: данные рангов,
изречения на китайском/пиньине/русском и векторные иллюстрации). Кнопка профиля — аватар в шапке главной.
- **30 дней похода, ранг каждые 3 зачтённых дня** (`Campaign.TOTAL_DAYS`, `DAYS_PER_RANK` в `src/js/campaign.js`).
- **Переход** — 400 очков за календарный день (≈ 20 минут занятий) → день зачтён (+1).
- **Марш-бросок 兼程** — 2000 очков (5× кап) → день зачтён за два.
- День без перехода → откат на день. Пропуски считаются с первой тренировки.
- Очки: верный ответ в тесте 2/3/5 (лёгкий/средний/сложный), письмо 4–6, карточки 1, экзамен 3; частичный — половина;
  бонусы: законченная тренировка от 10 вопросов +5, без ошибок +10, сданный экзамен +30.
- Очки фиксируются в каждой попытке (`attempt.points`) в момент сохранения — изменение формулы не переписывает историю.
- Состояние похода — контрольная точка `campaign` (`days`, `processedThrough`, журнал дней); продвигается только вперёд по календарю.
- Страница `docs/cats.html` — превью всех 10 иллюстраций.

## Сокровищница
За каждый день-марш-бросок (2000 очков) — сундук (`campaign.chests`), в нём 3 предмета (`src/js/treasures.js`, 22 предмета):
обычные 55 % · необычные 25 % · редкие 13 % · эпические 5,5 % · легендарные 1,5 %; первый предмет не ниже «необычного».
Ценность в 文 (вэнях): от связки монет (12) до императорской печати (9000). Инвентарь — в профиле; на что тратить — позже.

## Защита прогресса при обновлениях
`src/js/vault.js`: версия схемы данных (`meta.schema`), резервная копия всего (`backup:vN`) перед каждой миграцией,
миграции только вперёд и только добавляющие (ничего не удаляют), неизвестные поля сохраняются. Ежедневная лёгкая копия
`backup:auto`. Карточки HSK имеют стабильные ID по иероглифу (`hsk1:爱`), а не по номеру в списке — перестановка слов
в словаре не сдвигает статистику. Кэш service worker хранит только оболочку приложения; данные живут в IndexedDB.
Экспорт/импорт включает поход и схему; импорт старой копии проходит миграцию.

## Формат импорта текстом
По одной карточке в строке: `иероглиф;пиньинь;перевод;заметка` (разделители `;`, `|`, табуляция или пробелы). Тоны можно цифрами.
